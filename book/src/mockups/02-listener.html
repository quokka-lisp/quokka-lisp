Use case 1 · The listener as live text

The listener looks like a book's transcript, but any earlier form can be edited and run again. It runs as a new entry at the bottom, so the transcript stays a true record of what ran, in order.

Quokka's listener as live text: a transcript whose old forms can be edited and run again, with a side viewer listing this session's definitions.

Copies the ticked definitions, in order, into a new live-text file. The transcript stays as it is.
Return at the prompt runs the form · Cmd-Enter runs any form, anywhere in the transcript

It looks like the book: a prompt and a transcript. But the transcript is ordinary text. The side viewer notices which forms defined something, so a scratch session can become something kept.
