Use case 3 · Build a small application

A Rolodex: a class for its data, a viewer that says what to show, and commands, in CLIM's vocabulary. The running application is one more viewer, and it changes while it runs.

Building a Rolodex in Quokka: writing a class and a viewer, running it as a viewer among the others, and changing its display while it runs.

Quokka· world: my-apps.qipackage rolodex
Editor · rolodex
(defclass card () ((name :initarg :name :accessor name) (phone :initarg :phone :accessor phone) (email :initarg :email :accessor email))) (defvar *cards* '()) ; just objects in the world (define-viewer rolodex () (formatting-table () (dolist (c (sort-cards *cards*)) (formatting-row () (formatting-cell () (present c 'card)) (formatting-cell () (princ (phone c))))))) (define-command (new-card :viewer rolodex) () (push (accept 'card) *cards*))

The app opens as one more viewer. There's no separate program and no window of its own.
Cmd-Enter on each form installs it at once

An app is a class for its data, a viewer that says what to show, and commands. The vocabulary is CLIM's: present, accept, formatting-table. There's no HTML and no database: the cards are ordinary objects in the world. (Drawn before package-first development; in the design each of these forms is its own definition, and the cards would live in a private store.)
